NOWUP V196 — CORREÇÃO DE ARQUIVOS AUSENTES E NOVA MARCA

Este pacote atualiza o projeto existente. Não é um projeto independente.

COMO APLICAR
1. Extraia este ZIP no computador ou no gerenciador de arquivos.
2. Abra o MESMO repositório e a MESMA branch usados pelo serviço atual do Render.
3. Copie app.py, nowup_custom192.py e nowup_included195.py para a raiz do projeto.
4. Mescle a pasta static deste pacote com a pasta static existente no projeto.
5. Mescle a pasta templates deste pacote com a pasta templates existente.
6. Substitua somente os arquivos com os mesmos nomes. Preserve os demais.
7. Envie as alterações ao GitHub e publique o commit no serviço atual do Render.

Não envie apenas os arquivos Python. As pastas static e templates também são
necessárias. Não coloque este pacote dentro de static ou de templates e não
crie um segundo serviço ou banco. Nenhum banco de dados está incluído.

O QUE CORRIGE
- Inclui o arquivo de personalização que estava ausente no servidor.
- Usa custom196.js e custom196.css em ambos os templates que os carregam.

- O cabeçalho e rodapé passam a apontar diretamente para a nova logo.
- Reativa brand185.css e brand185.js e inclui as imagens necessárias.
